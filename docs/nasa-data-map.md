## MEDA numbers in the task

The curated Sol 290 extrema are −76.8 °C and −3.1 °C. The activity rounds them to −77 °C and −3 °C for an age-appropriate whole-number comparison: a difference of 74 °C. It asks which is colder, not which was taken at night. General facts about cold Mars nights do not establish timestamps for this particular pair.

The source note identifies Perseverance MEDA, Sol 290, December 13, 2021, degrees Celsius and archival rather than forecast data. Source-file SHA-256 values and the calculation method remain in the data/receipt files. Optional re-download/recomputation is `npm run verify:sources`; it needs Python 3 and access to NASA/PDS services. No new live download is claimed by a UI-only test run.

## Game assumptions and fiction

Energy/Oxygen/Safety points, Science rewards, profile dust schedules, the reserve release, old survey network, DUTİ and visitors are game design. They are not measured resource-consumption rates, radiation doses, extraterrestrial findings or NASA mission assets. Five endings reward different current-run histories; none increases Science or rescues a failed mission.

The interface exposes sources and archival qualifications. The official form should still explain each resource's actual contribution and list the sources/tools; linking only this table does not complete the form. Full third-party credits, license status and AI provenance are in [references](compliance/references.md), [AI_USAGE.md](../AI_USAGE.md) and [ai-usage.json](../ai-usage.json).
